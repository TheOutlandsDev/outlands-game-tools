# Worked toy-profile example

Run `create_example.py NEW_DIRECTORY` to make this original synthetic profile.
The destination must not exist and its parent must exist. No game, MO2
installation, download, or third-party asset is needed. The fixture is for
testing the report; its placeholder files are not an installable game mod.

The [main README](../README.md#try-a-small-example-without-a-game) has complete
PowerShell commands. Keep the JSON report outside the generated `mods`,
`overwrite`, and `profiles` input directories.

```text
NEW_DIRECTORY/
  profiles/Example/modlist.txt     # +Hotfix, -Disabled, +Base
  mods/
    Base/gamedata/
      configs/toy.ltx
      configs/unlocalizers/base.ltx
      scripts/menu.script
      textures/toy.asset
    Hotfix/gamedata/
      configs/toy.ltx
      configs/unlocalizers/hotfix.ltx
      scripts/settings.script
    Disabled/not-in-report.md
  overwrite/gamedata/textures/toy.asset
```

The native modlist places `Hotfix` above `Base` in file order (highest first).
`Disabled` is disabled. Supplying `--overwrite-dir` gives `<overwrite>` the
highest priority.

Expected summary:

```json
{
  "complete": true,
  "enabled_mods": 2,
  "scanned_providers": 3,
  "loose_files": 8,
  "effective_files": 6,
  "file_conflicts": 2,
  "lua_function_repeats": 1,
  "ltx_duplicate_keys": 1,
  "unlocalizer_duplicates": 1,
  "findings": 5
}
```

Expected provider names, highest first: `<overwrite>`, `Hotfix`, `Base`.

Expected overlap records (other JSON fields omitted here):

```json
[
  {
    "path": "gamedata/configs/toy.ltx",
    "providers_highest_first": ["Hotfix", "Base"],
    "winner": "Hotfix"
  },
  {
    "path": "gamedata/textures/toy.asset",
    "providers_highest_first": ["<overwrite>", "Base"],
    "winner": "<overwrite>"
  }
]
```

Expected text findings:

| Kind | Symbol/key | Locations |
|---|---|---|
| Lua repeat | `ui.refresh_menu` | `Base/gamedata/scripts/menu.script:1` and `Hotfix/gamedata/scripts/settings.script:1` |
| LTX duplicate | Section `toy`, key `speed` | `Hotfix/gamedata/configs/toy.ltx:2` and `:3` |
| Unlocalizer duplicate | `ui.refresh_menu` | `Base/gamedata/configs/unlocalizers/base.ltx:2` and `Hotfix/gamedata/configs/unlocalizers/hotfix.ltx:2` |

The original Base copy of `toy.ltx` is masked, so only Hotfix's effective copy
is checked for repeated keys. `toy.asset` is plain placeholder text with an
unparsed extension; it demonstrates file priority without shipping a game
texture. The disabled file must not appear in the inventory.

With `--fail-on-conflicts`, this example should exit **2**. Without the switch,
it should exit **0**. In both cases, findings remain in the report. An exit
code of 1 means the example did not complete; inspect its diagnostics rather
than accepting the expected counts.

You can edit this disposable fixture to try different scenarios: remove the
duplicate `speed` line, change one qualified function name, or rerun without
Overwrite to observe the changed winner. Use a new output filename each time.
The generator refuses reruns into an existing directory; preserve or remove
your disposable fixture manually after reviewing its location.
