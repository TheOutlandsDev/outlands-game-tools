# Fika wrapper provenance and license boundaries

The collection's existing Fika installer/configuration/pruning glue is original
local integration code. On 26 October 2026 the owner also confirmed that the
historical transfer-repair helper was their own work, including AI assistance.
The reviewed historical PowerShell input has SHA-256
`7974aa3b0fe9ef979be376d1b02d459facfbd3bc4c6782e19bf8f4abe5bafe05`.
The input is preserved privately and was not executed during this review.

The 2026 repair update improves the existing public module rather than adding
another repair application. Its new repair engine, restoration command,
fictional example generator, generated-file checks and documentation are
original contributions under the repository [MIT license](../../LICENSE).
The installer and pruning commands retain their earlier scope and behavior.

The private input's fixed paths/VPN defaults, automatic profile search, live
profile metadata, launcher-wide replacement, AI configuration templates and
game/mod payloads are excluded. Selected interoperable filenames and setting
names identify the files this wrapper edits; they are not upstream source.
No Fika, SPT, EFT, plugin implementation, installer executable or runtime is
bundled or relicensed. Obtain those separately under their applicable terms.
Windows, PowerShell and .NET also remain separately supplied runtimes.

Public examples contain fictional data only. The tool's own local previews,
errors and recovery manifests can reveal selected paths, profile labels and
configuration fingerprints; original backup bytes can contain private data.
None of these runtime outputs is intended for public upload. MIT does not
grant rights to a user's inspected files or generated backups.
